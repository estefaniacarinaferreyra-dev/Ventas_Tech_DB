 # RetailPro – Proyecto de Análisis de Datos

## Descripción del proyecto

RetailPro es un proyecto de análisis de datos orientado al estudio de información de ventas. El objetivo es transformar los datos disponibles en información útil para el análisis comercial, aplicando un flujo de trabajo que incluye consultas SQL, procesos ETL, modelado, cálculos y visualización.

## Herramientas utilizadas

- SQL Server: consultas y análisis de datos.
- Power Query: procesos ETL, limpieza y transformación de datos.
- Power BI: modelado y visualización de la información.
- DAX: creación de medidas y cálculos para el análisis.

## Tablas principales

La base de datos utilizada es Ventas_Tech_DB y contiene como tablas principales:

- ventas
- clientes
- productos
- categorias

Estas tablas se relacionan para integrar la información necesaria para el análisis de ventas.

## Estructura general del análisis

El proyecto se desarrolla en diferentes etapas:

1. Consulta y exploración de los datos mediante SQL.
2. Integración de las tablas mediante JOIN.
3. Limpieza y transformación de datos utilizando Power Query.
4. Creación del modelo de datos y definición de relaciones.
5. Creación de medidas DAX.
6. Construcción de visualizaciones para comunicar los principales resultados.

## Análisis realizados

Entre los análisis desarrollados se encuentran:

- Facturación mensual.
- Ranking de productos.
- Identificación de clientes recurrentes.
- Comparación de los meses respecto del promedio de facturación.

## Ejecución de los scripts SQL

Para ejecutar los scripts SQL:

1. Abrir SQL Server Management Studio.
2. Conectarse al servidor correspondiente.
3. Seleccionar la base de datos Ventas_Tech_DB.
4. Abrir el archivo SQL que se desea ejecutar.
5. Ejecutar las consultas y verificar los resultados obtenidos.

## Objetivo del análisis

El análisis permite estudiar el comportamiento de las ventas desde distintas perspectivas, como la evolución de la facturación, el desempeño de los productos y el comportamiento de los clientes.

## Consideraciones

Los resultados generados mediante consultas, transformaciones y medidas deben ser validados antes de utilizarse para obtener conclusiones de negocio.
